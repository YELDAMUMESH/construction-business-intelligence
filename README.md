# Construction Business Intelligence

## Project Overview

This repository documents my six-week Virtual Construction Business Intelligence internship. The project explores how data analytics and Microsoft Power BI can support construction project monitoring and business decision-making.

## Objectives

- Understand construction business intelligence requirements.
- Identify key performance indicators (KPIs) for project monitoring.
- Explore construction data quality and preparation.
- Plan reporting solutions for cost, schedule, safety, and resource utilization.
- Document the analytical process and findings throughout the internship.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- Microsoft Excel
- CSV datasets
- GitHub
